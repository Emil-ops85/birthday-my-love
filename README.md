# 🎂 Сайт «День рождения для Маши»

Интерактивный сайт-поздравление с днём рождения для **Маши** — нежный пастельно-розовый дизайн с котиками, сердечками, музыкой и конфетти.

## 🗂 Структура

```
├── index.html            — разметка и все слайды
├── css/style.css         — вся стилизация и анимации
├── js/main.js            — вся логика
├── img/cat1.gif … cat8.gif — котики (GIF на каждый слайд)
├── audio/precious-memories.mp3 — фоновая музыка
└── README.md             — этот файл
```

## ✨ Как устроено

- **8 слайдов** — «путешествие» по поздравлению: от «появилась на свет» до финального «С Днём Рождения, Маша 🎂». На каждом слайде — котик, заголовок, подзаголовок и кнопка «Дальше».
- **Финальный сюрприз** — открытка с печатающимся текстом (typewriter), конфетти и надпись «Люблю тебя бесконечно 💛». Есть кнопка «Начать заново».
- **Управление**: кнопки, стрелки клавиатуры, свайпы на телефоне, точки-прогресс внизу.

## 🛠 Ключевые особенности

- **Музыка** 🎵 с кнопкой-переключателем, автоплей + запуск по первому жесту (обход блокировки браузера).
- **Кнопка-сердечко** 💗 — взрыв из 26 сердечек из кнопки.
- **След из сердечек** за курсором (только на устройствах с мышью).
- **Фоновые эффекты**: сердечки (только справа), мерцающие звёздочки, падающие блёстки, проплывающие котики, плавная смена градиента фона.
- **Звуковые эффекты** — мягкие «pop» и «click» через Web Audio API (без файлов).
- Имя **«Маша»** выделено радужным переливающимся градиентом.

## 📱 Важные заметки по мобильным (iOS Safari / Telegram)

- **GIF на iPhone**: анимация котиков работает, если на устройстве включено **«Автовоспроизведение анимированных изображений»** (Настройки → Универсальный доступ → Движение). Эта настройка влияет только на GIF.
- **Telegram**: встроенный браузер Telegram использует отдельный WebView. Чтобы GIF корректно отображались и там, **оформление котиков (рамка, тень, свечение, покачивание) должно быть прямо на самом `<img>`**, а не на обёртке `.cat-wrap` — анимация на предке картинки в WebView Telegram замораживает/прячет GIF.
- **Вывод**: пока не переходим на `<video>`/mp4 — гифки работают и в Safari, и в Telegram при включённой настройке автовоспроизведения.
